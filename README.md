## 📱 نصب نسخه اندروید (APK)

فایل نصبی آماده: **[`apk/AntiHack-v1.3.0.apk`](apk/AntiHack-v1.3.0.apk)** (حدود ۳۵۰ کیلوبایت)

- حداقل اندروید: **۵.۰ (API 21)** — هدف: Android 14 (API 34)

- **بررسی بروزرسانی**: از بخش تنظیمات می‌توانید نسخه نصب‌شده را با آخرین نسخه منتشرشده در گیت‌هاب مقایسه و در صورت وجود نسخه جدید، آن را مستقیماً از داخل برنامه دانلود و نصب کنید.

- کاوشگر دسترسی‌های حساس (پیامک/GPS/دوربین/مخاطبین/میکروفون)

## 🌐 اجرای نسخه وب

```bash
bun install
bun run db:push     # ساخت دیتابیس SQLite
bun run db:seed     # درج ۲۰ درس + ابزارها + برنامه‌های شبیه‌سازی‌شده
bun run dev         # http://localhost:3000
```

## 🤖 ساخت APK از سورس

```bash
# ۱) ساخت assets آفلاین تک‌فایلی (تزریق دیتا + آیکون‌ها + فونت‌ها)
node android/scripts/build-assets.mjs

# ۲) کامپایل، بسته‌بندی و امضای APK
#    (نیازمند: JDK + Android build-tools + platform android.jar + ECJ)
bash android/scripts/build-apk.sh
```

ساختار اپ اندروید: `android/app/src/main` — یک `MainActivity` با WebView که `assets/index.html` (کل اپ در یک فایل HTML مستقل) را بارگذاری می‌کند؛ دکمه بازگشت به ناوبری پشته‌ای اپ متصل شده است. پل بومی `AndroidBridge` وظیفه بررسی نسخه از API گیت‌هاب، دانلود APK با نوار پیشرفت و بازکردن نصاب سیستم (`ApkProvider` برای اشتراک امن فایل) را بر عهده دارد.

## 🏗️ تکنولوژی نسخه وب

Next.js 16 (App Router) + TypeScript + Tailwind CSS 4 + shadcn/ui + Prisma (SQLite) + Zustand + Framer Motion

| API | شرح |
|---|---|
| `GET /api/bootstrap` | داده‌های اولیه (درس‌ها، ابزارها، میانبرها، چک‌لیست) |
| `GET /api/lessons/[id]` | متن کامل یک درس |
| `GET /api/apps` | لیست برنامه‌های شبیه‌سازی‌شده با فیلتر |
| `POST /api/scan` | اسکن مرحله‌ای/کامل سپر طلایی |
| `POST /api/scan/fix` | رفع خودکار مشکل امنیتی |
| `POST /api/pro/purchase` | فعال‌سازی پرو (مایکت) |
